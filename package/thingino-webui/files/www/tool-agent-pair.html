Prefer pairing from the Thingino Hub whenever possible (Connect → Install Pairing Bundle). The hub generates the bearer token and installs it on this camera. Use this page only if MQTT bootstrap is unavailable: paste the hub-issued token from Hub → Enroll → Show Pairing Details (or from a pairing install summary), then save. Do not invent a random token here unless you also store that exact same token in the hub.

Leaving MQTT fields alone keeps the current broker settings. Day-to-day MQTT edits belong under Services → MQTT Subscriptions.
