Decision source

What decides Day/Night, and which calendar it may use

The camera stores one calendar, not a choice between two, so picking one clears the other one's values on save. With “Light level” a calendar is optional - it only sharpens when a forced probe is due.

Local camera clock. The night window may wrap past midnight (e.g. night 20:00, day 06:30).
