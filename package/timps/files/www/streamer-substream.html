Rate control

Saved instantly. Fields the camera can apply to the running encoder take effect at the next keyframe; everything else needs a streamer restart — each save says which. Which fields do anything depends on the mode and SoC: quality level and change position count only for VBR/SMART on the older SoCs (T10…T30), fixed QP only in FIXQP mode. Measured on T23: the controller is quality-seeking, so Min QP is the strongest lever (raising it lowers the bitrate); quality level moves it more gently; change position showed no measurable effect there.
