Fixes the silent no-op in `sysupgrade -B` / `sysupgrade -f -B`: `cfg-backup` was referenced by `sysupgrade` (line ~925, `cfg-backup write 2>/dev/null`) but never installed by any package, so backups silently never happened and `cfg-backup restore` did not exist on cameras.

## What it does

- Ships `scripts/cfg-backup.sh` as `/usr/sbin/cfg-backup` via the **thingino-sysupgrade** package (`SITE_METHOD = local`, zero new deps — uses busybox tools already present: `tar`, `dd`, `md5sum`, `stat`, `awk`, `sed`, `grep`, plus `flash_eraseall`/`flash_erase` + `flashcp` from mtd-utils).
- Existing `/etc/cfg-backup.list` overlay file already ships in rootfs — unchanged.
- sysupgrade integration unchanged: it now finds `cfg-backup` in PATH.
